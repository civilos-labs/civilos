# Agent Protocol

## Purpose

The Agent Protocol defines how agents communicate, collaborate, challenge assumptions, and build collective intelligence inside CivilOS.

The objective is to ensure that agents do not operate independently, but as part of a coordinated intelligence network.

# Agent Roles

## Research Agent

Discovers information, evidence, trends, and signals.

---

## Science Agent

Validates scientific credibility and factual support.

---

## Economics Agent

Evaluates economic impact and consequences.

---

## Policy Agent

Analyzes regulatory, governance, and policy effects.

---

## Critic Agent

Challenges findings, identifies weaknesses, and prevents false conclusions.

---

# Debate Process

1. Research Agent proposes findings.

2. Science Agent validates evidence.

3. Economics Agent evaluates impact.

4. Policy Agent evaluates consequences.

5. Critic Agent challenges assumptions.

6. Agents revise conclusions.

7. Final recommendation is generated.

---

# Memory Integration

All discoveries are stored in Memory Layer.

Validated knowledge is added to the Knowledge Graph.

Agent performance is recorded in the Trust Layer.

---

# Collective Knowledge Rule

No single agent can create permanent knowledge alone.

All permanent knowledge must:

- Be supported by evidence.
- Survive criticism.
- Be validated by multiple agents.
- Be traceable to sources.
- Be eligible for Memory Layer admission.

Individual agents may propose hypotheses.

Collective intelligence validates knowledge.

Only validated knowledge may enter permanent memory.

# Collective Decision Principle

Agents do not compete to be right.

Agents collaborate to discover the most defensible conclusion.

The objective is not agreement.

The objective is validated knowledge.

Disagreement is valuable when supported by evidence.

---

# Agent Validation Criteria

## Research Agent

Successful when:

- Provides traceable evidence.
- Identifies relevant signals or discoveries.
- Uses accepted evidence sources.
- Produces hypotheses that survive review.

Fails when:

- Uses unsupported claims.
- Uses rejected evidence.
- Provides information without sources.

---

## Science Agent

Successful when:

- Validates scientific credibility.
- Detects methodological weaknesses.
- Confirms evidence quality.

Fails when:

- Approves weak evidence.
- Ignores contradictory evidence.
- Accepts unsupported claims.

---

## Economics Agent

Successful when:

- Identifies economic impacts supported by evidence.
- Connects risks to measurable consequences.
- Produces defensible impact analysis.

Fails when:

- Makes unsupported predictions.
- Uses speculative conclusions.
- Ignores available evidence.

---

## Policy Agent

Successful when:

- Identifies relevant regulatory or governance impacts.
- Uses verifiable policy evidence.
- Detects implementation risks.

Fails when:

- Makes unsupported policy claims.
- Ignores regulatory evidence.
- Invents consequences without validation.

---

## Critic Agent

Successful when:

- Identifies logical weaknesses.
- Detects contradictions.
- Challenges unsupported assumptions.
- Improves final knowledge quality.

Fails when:

- Rejects valid evidence without justification.
- Creates unsupported criticism.
- Blocks validated conclusions without cause.

---

# Collective Validation Rule

CivilOS does not measure success by agent activity.

CivilOS measures success by validated knowledge creation.

An agent succeeds only when its contribution survives evidence review, criticism, and collective validation.

---

# Long-Term Goal

Create a collaborative society of agents capable of producing better decisions than any individual agent alone.

---

# Core Principle

The goal is not participation.

The goal is validated knowledge.

Agents generate ideas.

Collective intelligence creates knowledge.

If a contribution cannot be validated, it must not be trusted.

If a conclusion cannot be validated collectively, it must not become permanent knowledge.

If it is not real, it is not shown.
