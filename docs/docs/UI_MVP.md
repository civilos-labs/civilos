# CivilOS UI MVP

## Layout

Three-column interface.

### Left Panel

Single Agent

Shows:

- One hypothesis
- One answer
- Confidence score

Purpose:

Demonstrate the limitations of individual intelligence.

---

### Center Panel

CivilOS Process

Components:

- Research Agent
- Skeptic Agent
- Impact Agent
- Memory Agent
- Synthesis Agent

Displays:

- Hypotheses generated
- Hypotheses rejected
- Debate status
- Active reasoning process

---

### Right Panel

Knowledge Graph

Dynamic graph showing relationships between:

- Risks
- Events
- Consequences
- Opportunities

Graph grows during execution.

---

## Bottom Panel

### Trust Layer

Displays agent reputation scores.

### Evidence Layer

Displays:

- Sources
- Counterarguments
- Confidence

### Final Conclusion

Displays final collective intelligence output.

---

## Demo Goal

Show that CivilOS produces stronger conclusions than an individual agent through collective reasoning.
