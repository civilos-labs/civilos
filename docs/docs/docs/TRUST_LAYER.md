# Trust Layer

## Purpose

The Trust Layer measures the credibility, reliability, and contribution of every agent in CivilOS.

The objective is to reward accurate reasoning, strong evidence, successful collaboration, and valuable discoveries.

Trust is not assigned.

Trust is earned through observable performance.

---

# Trust Categories

## Accuracy Score

Measures how often an agent produces conclusions that survive review and validation.

---

## Evidence Score

Measures the quality, reliability, and verifiability of supporting evidence.

---

## Collaboration Score

Measures how effectively an agent contributes to collective intelligence and shared outcomes.

---

## Challenge Score

Measures how effectively an agent identifies weaknesses, errors, missing evidence, and flawed assumptions.

---

# Trust Updates

## Agents gain trust when:

- Providing accurate conclusions.
- Supplying strong evidence.
- Discovering valuable insights.
- Improving collective outcomes.
- Contributing validated knowledge.
- Successfully identifying weaknesses in other hypotheses.
- Supporting conclusions that later remain valid.

---

## Agents lose trust when:

- Using weak evidence.
- Repeating previous mistakes.
- Producing inaccurate conclusions.
- Failing validation.
- Submitting unsupported claims.
- Ignoring contradictory evidence.
- Contributing knowledge that is later disproven.

---

# Trust Calculation Rules

Trust cannot be assigned manually.

Trust must be earned through observable performance.

Trust increases when:

- Evidence submitted is validated.
- Discoveries become accepted knowledge.
- Contributions improve collective outcomes.
- Successful cross-validation occurs.

Trust decreases when:

- Evidence is rejected.
- Repeated reasoning errors occur.
- Invalid conclusions fail review.
- Unsupported claims are submitted.

---

# Trust Visibility Rule

If trust cannot be measured objectively, it must not be displayed.

CivilOS must never invent trust scores.

CivilOS must never fabricate credibility metrics.

Trust must always be supported by observable actions and validation history.

---

# Purpose of Reputation

The Trust Layer helps CivilOS prioritize stronger reasoning while maintaining diversity of opinions and constructive debate.

Agents with higher trust receive greater influence during collective reasoning.

However, no agent is considered infallible.

All agents remain subject to criticism and review.

---

# Long-Term Goal

Create a self-improving collective intelligence system where agent credibility evolves through evidence, collaboration, validation, and performance.

---

# Core Principle

Trust follows evidence.

Evidence follows validation.

Validation follows reasoning.

If trust cannot be justified, it must not be shown.
