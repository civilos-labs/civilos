# Measurable Validation Criteria

CivilOS succeeds only when the following conditions are met:

- Accepted conclusions have supporting evidence.
- Accepted conclusions survive criticism.
- Accepted conclusions are validated by multiple agents.
- Knowledge is stored in memory.
- Knowledge can be reused in future investigations.
- Relationships added to the Knowledge Graph are evidence-backed.
- Trust scores can be audited.
- Conclusions remain traceable to sources.

If any of these conditions fail, the knowledge creation process is considered incomplete.

---

# Technical Success Metrics

CivilOS should measure:

- Number of validated hypotheses.
- Number of rejected hypotheses.
- Evidence sources used.
- Knowledge entries created.
- Knowledge entries reused.
- Knowledge Graph relationships validated.
- Cross-agent validations completed.
- Auditability rate of conclusions.

These metrics must be generated from real system activity.

If a metric cannot be measured, it must not be displayed.

# Success Definition

CivilOS succeeds when validated knowledge created today improves future investigations tomorrow.
